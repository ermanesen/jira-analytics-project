# Generated exports

Run `python scripts/run_pipeline.py` with `PYTHONPATH=src`. The pipeline writes:

- `monthly_kpis.csv`
- `customer_lifecycle.csv`
- `cohort_continuation.csv`
- `product_performance.csv`
- `country_performance.csv`
- `data_quality_results.csv`

These CSVs are generated artifacts. The README remains in Git so the handoff folder is visible before the first local build.
