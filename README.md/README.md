Customer Spending and Loyalty Analysis (End-to-End)

In this project, I analyzed the spending habits of an e-commerce company using customer usage and loyalty data.

#Tech Stack

Data: Customer usage and spending data (CSV) 
Data Processing: SQL and DuckDB 
Visualization: Power BI

#Project Phases (End-to-End Process)

Data Loading: Transferred raw CSV data into DuckDB using SQL.
Cleaning: Removed incorrect spending data (negative values) and formatted text fields (TRIM).
Transformation: Segmented customers based on their membership duration (e.g., 0-1 year, 1-2 years, etc.) to enable deeper insights.
+1

Analysis: Used SQL to calculate key metrics such as average spending per segment and platform usage impact.

Dashboard: Visualized the final insights on an interactive Power BI dashboard.

#Key Insights

Loyalty Pays Off: Customers with over 4 years of membership spend significantly more than newer customers.
+1
Mobile First: The time customers spend on the mobile app has a higher correlation with increased spending compared to time spent on the website
